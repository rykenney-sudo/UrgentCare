Components

Buttons

One button shape site-wide: 11px radius, 13/22px padding, Open Sans 700 at 9.75 pt, uppercase with .03em tracking, and a solid icon before the label.

On light

Call 781-255-0500 Get Directions

On navy

Call 781-255-0500 Get Directions
Primarywhite fill, navy label; hover #e8f4fb Ghosttransparent, 50% white border; hover fills rgba(255,255,255,.13)

Do

  • Exactly one primary button per section.
  • Pair it with a ghost secondary, never two solids.
  • Full-width buttons below 640px.

Don't

  • Introduce new fills — teal, gradient, or the old --ink navy.
  • Use sentence case or drop the letter-spacing.
  • Mix outline icons into buttons.

Foundations

Icons

Filled glyphs only. Material Symbols for interface actions, Healthicons for medical concepts.

Concept icons

36px, --er red, no tile or tinted background. Used on service, pricing, and body-part cards.

Action icons

16px inside buttons, inheriting the label color via .mi (fill:currentColor). Phone, pin, and message are fixed glyphs — don't substitute.
